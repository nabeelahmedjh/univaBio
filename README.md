# univaBio

A doctor–patient follow-up assistant. A consultation **session** stores the
conversation **transcript** and an embedded **clinical report** generated by
Gemini. Audio is transcribed locally with Whisper.

The project has two parts:

- **Backend/** — FastAPI + SQLite API
- **Frontend/** — React + TypeScript + Vite app

## Prerequisites

- Python 3.10+
- Node.js 18+

## 1. Backend

```bash
cd Backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env            # then edit .env
```

In `.env`, set at minimum:

- `JWT_SECRET_KEY` — a long random string
  (generate one: `python -c "import secrets; print(secrets.token_hex(32))"`)
- `SUPER_ADMIN_USERNAME`, `SUPER_ADMIN_PASS`
- `GEMINI_API_KEY` — free key from https://aistudio.google.com/app/apikey

Run the server:

```bash
uvicorn app.main:app --reload
```

- API docs: http://127.0.0.1:8000/docs
- Health check: http://127.0.0.1:8000/health

Optionally seed demo data (doctor `drsmith` / patient `+15550001111`):

```bash
python seed.py
```

## 2. Frontend

Open a second terminal (keep the backend running):

```bash
cd Frontend
npm install

cp .env.example .env.local      # defaults point at http://localhost:8000
```

Run the dev server:

```bash
npm run dev
```

The app is served at http://localhost:5173.

## Notes

- Keep both terminals running: backend on `:8000`, frontend on `:5173`.
- Without a `GEMINI_API_KEY`, sessions still save the transcript with
  `report_status = "pending_key"`.
